# P.H.O.E.N.I.X. v1.0.0 — Initial Official Release 🚀

**Personalized Holographic Operator for Execution, Navigation, & Interactive eXtension**

We are thrilled to announce the official **v1.0.0** release of **P.H.O.E.N.I.X.**, a lightweight, 100% offline Windows desktop AI assistant featuring a floating holographic 3D Dyson Sphere, direct OS execution, and silent ambient speech filtering on 4 GB RAM.

---

### 🌟 What's Included in v1.0.0

- **3D Holographic Dyson Sphere (v3.0):**
  - 20 dense, nested multi-axis toroids revolving across X, Y, and Z axes.
  - Zero-clipping viewport with 3,200 dynamic particle embers.
  - Smooth **top-to-bottom Ultron Blue wave transition** upon entering sleep/standby mode.
  - 100% transparent borderless overlay that floats over any application or desktop wallpaper.
- **100% Offline Speech Recognition:**
  - Local Vosk neural speech engine stored directly in project `models/`. Zero cloud transmission.
  - Fast response times (<50ms execution).
- **Strict Silent Ambient Speech Filtering:**
  - Filters all incoming audio against registered commands.
  - Ambient room conversation is silently ignored without intrusive failure sounds or popups.
- **Personalized Assistant Persona:**
  - Configurable user name (defaults to Swayam).
  - Welcomes user on launch and wake: *"At your service, Swayam."*
- **Specialized Workflows:**
  - *"Learning mode Perplexity"* opens custom **Comet Browser** directly.
  - *"Coding mode VS Code"* and *"Coding mode Antigravity"*.
  - Dynamic Google multi-account switching (*"Switch to account 1"* up to 5+ accounts).
  - Voice file operations (*"Open PDF report"*, *"Open Word thesis"*, *"Create folder notes"*).
  - Automatic screenshot capture directly to `Downloads/` and clipboard.
  - Master volume, battery status, and real-time clock announcements.

---

### 📦 Windows Installation Instructions

1. Download **`PHOENIX_Setup.exe`** from the Assets below.
2. Double-click the installer to start the setup wizard.
3. *(If Windows SmartScreen prompts "Windows protected your PC", click **"More info"** &rarr; **"Run anyway"**)*.
4. Launch P.H.O.E.N.I.X. from your Desktop or Start Menu.
5. Click the floating 3D core to awaken the assistant!

---

### 💻 System Requirements
- **Operating System:** Windows 10 / Windows 11 (64-bit)
- **RAM:** Minimum 4 GB (Runs with ~120 MB memory usage)
- **CPU:** Dual-core 2.0 GHz or higher (CPU-only, no dedicated GPU required)
- **Disk Space:** ~250 MB free space
